single-node local kind cluster. Ginkgo passed all three specs with no skips in
93.511 seconds. One spec covers the deployed lifecycle. Two cover the fixture's
command-output handling. This is functional acceptance, not a capacity result.

## Retained initial failure

The first run failed after 75.259 seconds. It had already passed the missing-CRD,
image-identity, Prometheus-family and direct-exposition checks. Kubernetes wrote
an Endpoints deprecation warning to stderr. The fixture combined stderr with
stdout and treated warning words as API addresses. Kubernetes rejected the
resulting NetworkPolicy CIDRs before policy enforcement was tested.

Fixture commit `cefec2b3` separates successful stdout from diagnostics. Stderr
remains in the Ginkgo log and in failed-command output. Two subprocess regression
specs passed, and independent review found no issues. Only the monitoring fixture
changed. The monitoring cluster was recreated with the same pinned setup and the
same final image before the successful run. All acceptance assertions and time
limits were retained.
