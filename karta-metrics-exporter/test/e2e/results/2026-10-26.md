## Evidence and scope

The independent oracle followed real controller owner references. Each metric
case verified root and Pod UIDs, root GVK, selected Karta, all nine status values,
creation timestamp, exact component coordinates and resource collection health.
It then changed the `team` label and verified replacement on Pod and status
metrics. Foreground root deletion removed every series for that root and its
owned Pods.

The [portable evidence](2026-10-26-final-operator-evidence.json) preserves those
identities, controller conditions, metric values, image identities, installed
operator versions and SHA-256 hashes of the raw artifacts. It omits node names,
IP addresses, local API endpoints and home-directory paths. Raw Ginkgo JSON,
JUnit, root/Pod objects and Prometheus captures remain in the local directories
`/tmp/exporter-e2e-final-c4a44553-default`,
`/tmp/exporter-e2e-final-c4a44553-pod-default` and
`/tmp/exporter-e2e-final-c4a44553-alternate`, with sibling `.log` files.

Completed and failed Jobs ran real Pods before the suite removed their terminal
Pods. The suspended Job started without Pods. NIMCache exercised an actual
NotReady reconciliation failure caused by an absent PVC. Dynamo, NIM and
LLMInferenceService used CPU test backends. These results prove the fixture
states and exporter attribution described in the [matrix README](../README.md).
They do not prove every operator lifecycle state, successful NIMCache downloads
or GPU inference. The suite removed its exporter release and workload namespaces
and retained the installed operators.
